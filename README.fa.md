# سامانهٔ تحت وب CDI — نمونهٔ اولیه

پیاده‌سازی تحت وبِ چارچوب عملیاتی «ارزیابی جامع CDI» برای تبدیل خروجی EM-MPI به تصمیم مداخله‌ای (بندهای ۱ تا ۹ سند چارچوب).

## اجرا

```bash
.venv/Scripts/python main.py
# سپس در مرورگر:  http://127.0.0.1:5000
```

داده‌ها در `cdi_data.json` ذخیره می‌شود (سه خانوار نمونهٔ از پیش تعریف‌شده دارد). برای شروع پاک، فایل را حذف کنید.

## نقش‌ها (گذرواژهٔ همه: `1234`)

| کاربر | نقش | حلقه |
|---|---|---|
| `assistant` | همیار مددکار | حلقه ۱ (بیرونی‌ترین) |
| `rose` | کلینیک تخصصی مشاوره «رز» | حلقه ۲ |
| `swclinic` | کلینیک تخصصی مددکاری | حلقه ۳ |
| `worker` | مددکار خانواده کمیته امداد | حلقه ۴ (هسته مرکزی، مالک پرونده) |
| `employ` | کارشناس اشتغال | حلقه تخصصی |
| `manager` | مدیر خدمت / مقام مجاز | حلقه تخصصی |

## جریان کاری

1. **لایه ۱ (CDI سریع):** ایجاد پرونده با کارت ورودی EM-MPI (سطح محرومیت، پرچم‌های قرمز، ابعاد غالب) → فعال‌سازی شاخه‌ای محورها از میان **۴۱ محور** پنج بُعد.
2. **لایه ۲ (CDI هدفمند):** پرسشنامهٔ پویا فقط برای محورهای فعال؛ هر نقش فقط محورهای مجاز ماتریس بند ۳ را می‌بیند و ثبت می‌کند؛ همیار روی محورهای حساس **فقط هشدار** ثبت می‌کند.
3. **دروازهٔ لایه ۳:** ورود به CDI عمیق فقط با شرایط ۹گانهٔ بند ۴ـ۱ (پرچم قرمز، چندمسئله‌ای، تعارض داده، مداخله پرهزینه، …) — ثبت نتیجه فقط با کلینیک رز، کلینیک مددکاری یا مددکار.
4. **تصمیم مددکار:** تأیید/اصلاح اولویت P0–P4 پیشنهادی سامانه، ورود به لایه ۳ و ارجاع به حلقه‌ها (بند ۲ـ۲).
5. **پروفایل توانمندسازی:** خروجی رسمی بند ۸ با ۱۶ جزء الزامی، گلوگاه‌ها، ریسک‌نامه و برنامهٔ پایش.
6. **کاتالوگ:** مرجع کامل ۴۱ محور، منابع داده (E/S/D/H/B/M/T)، حلقه‌های اجرایی و خط قرمزها.

## خط قرمزهای اعمال‌شده در کد (بند ۹ـ۲)

- سامانه فقط **پیشنهاد** می‌دهد (`is_recommendation`)؛ تصمیم نهایی فقط با مددکار خانواده (`/decide` برای غیرمددکار → 403).
- همیار حق امتیازدهی محورهای حساس را ندارد — فقط هشدار با `severity=none`.
- ورود به لایه ۳ بدون قاعدهٔ بند ۴ـ۱ مسدود است؛ همیار و کارشناس اشتغال حق ثبت لایه ۳ ندارند.
- خروجی موتور شامل دلیل، منبع داده و سطح اطمینان است.

## ساختار پروژه

```
main.py           اپلیکیشن Flask (نقش‌ها، مسیرها، گاردهای دسترسی)
cdi_catalog.py    کاتالوگ: ۵ بُعد، ۴۱ محور، حلقه‌ها، اولویت‌ها، خط قرمزها
cdi_engine.py     موتور قواعد: فعال‌سازی شاخه‌ای، P0–P4، توالی، پروفایل
cdi_data.json     دادهٔ نمونه/محل ذخیره
templates/        قالب‌های RTL فارسی (Vazirmatn)
```

## محدودیت‌های نمونهٔ اولیه (گام‌های بعدی)

- احراز هویت واقعی + CSRF کامل + ثبت حسابرسی تغییرناپذیر
- پایگاه دادهٔ واقعی (PostgreSQL) به‌جای JSON
- اتصال به سامانهٔ سها و موتور EM-MPI
- بارگذاری مدارک، داشبورد تجمیعی مدیر خدمت، اعلان‌ها و یادآوری مهلت‌ها
