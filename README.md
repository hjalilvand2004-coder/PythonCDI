# سامانه CDI — شناسایی، احراز، توانمندسازی (Python/Flask)

سامانه‌ی تحت وب کمیته امداد برای غربالگری محرومیت چندبعدی خانوار (EM-MPI) و ارزیابی جامع (CDI).

## نسخه ۲.۰ — بازطراحی مبتنی بر reference پرسشنامه

این نسخه موتور EM-MPI را به‌صورت وفادارانه از مخزن مرجع
[`porseshnameh`](https://github.com/hjalilvand2004-coder/porseshnameh)
(Next.js/TypeScript) به Python/Flask منتقل کرده است.

### ساختار

- `emmpi_engine.py` — موتور امتیازدهی قطعی (port از `src/lib/mpi/` مرجع)
- `main.py` — برنامه Flask با همه مسیرها
- `cdi_catalog.py` — کاتالوگ شاخص‌ها و محورهای CDI
- `cdi_engine.py` — موتور CDI (لایه‌های ۲ و ۳)
- `web_services.py` — وب‌سرویس‌های فرضی قدیمی
- `iran_geo.py` — داده‌های جغرافیایی ایران
- `finance_engine.py` — سیستم مالی (کیف پول + هزینه خدمات)
- `templates/` — قالب‌های Jinja2
- `cdi_data.json` — پایگاه داده JSON
